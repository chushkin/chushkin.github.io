# Brain Evolution · GitHub Pages

Статическая продуктовая страница на существующем сайте Eugene Chushkin. Не использует сторонний хостинг, сборщик, CDN, внешние шрифты, аналитику или аккаунты.

- `index.html` — русский вариант: `/brain-evolution/`.
- `en/index.html` — английский вариант: `/brain-evolution/en/`.
- `styles.css`, `app.js` — общий адаптивный дизайн и локальные взаимодействия.
- `assets/` — WebP, превью JPEG и manifest происхождения.
- `support/` — отдельная страница поддержки; обслуживается отдельно от генератора landing.

## Статус версий: важная часть содержания

По проверке живых страниц магазинов владельцем задачи **25 октября 2026**: App Store — **1.0.7**, RuStore — **1.1.8**. **1.2.0 ещё готовится к публикации**.

Все 13 игр, новые игровые экраны, звёзды/ранги и другие детали 1.2.0 на landing показаны как **превью будущего обновления**. Это явно указано в hero рядом с кнопками, у заголовка и подписи галереи, в секции скачивания и FAQ. Кнопки ведут на существующие страницы приложения с текущими опубликованными версиями. Google Play CTA отсутствует: публичная страница приложения на момент проверки возвращала 404.

После выхода 1.2.0 нужно сначала проверить живые страницы магазинов, затем обновить словари `COPY` в `_tools/build_pages.py` и пересоздать HTML. Не убирать preview-маркировку до фактической публикации. Ссылка на конфиденциальность ведёт на существующую `https://sites.google.com/view/chushkin`; незавершённые черновики политики на сайте не размещаются.

## Пересоздание страниц

```sh
python3 brain-evolution/_tools/build_pages.py
```

Команда запускается из корня GitHub Pages checkout и генерирует только два landing HTML. Контент RU/EN, корректные canonical/hreflang, Open Graph и SoftwareApplication JSON-LD формируются одним исходником. Корневой `index.html`, корневой `styles.css` и `brain-evolution/support/` не изменяются.

## Изображения

Веб-изображения основаны на материалах Unity-проекта BrainEvolution:

- `Builds/AppStore/1.2.0/Source/Artwork/brain-evolution-keyart-v1.png` — AI-промоиллюстрация по существующей иконке. Это рекламный персонаж, не игровой интерфейс.
- `Builds/iOS/Unity-iPhone/Images.xcassets/AppIcon.appiconset/Icon-Store-1024.png` — настоящая иконка сборки.
- `Builds/AppStore/1.2.0/Source/Captures/{iphone,ipad}/{ru,en-US}/` — настоящие экраны Numbers, Memorics, Sudoku и Quadronica.

Снимки сделаны в iOS Simulator на отдельной инструментальной сборке 1.2.0: автопереходы и остановка времени для кадра. Интерфейс и результаты не перерисовывались. Это не скриншоты текущих опубликованных версий и не ручной E2E тест релизного IPA.

Кадры пропорционально уменьшены и сжаты в WebP. Игровой экран показывается целиком, без растяжения и обрезки; переключатель iPhone/iPad использует собственные снимки каждой платформы. Все 20 изображений вместе занимают примерно **1.01 MB**; страница загружает подходящий размер hero и лениво загружает игровые экраны. Манифест хранит исходный путь и SHA-256, без приватных абсолютных путей.

Для повторной оптимизации из полного Unity workspace нужен Pillow:

```sh
python3 brain-evolution/_tools/prepare_assets.py --project /path/to/BrainEvolution_2026
```

## Взаимодействия и доступность

- Четыре категории охватывают ровно 13 конкретных игр.
- Tabs поддерживают стрелки влево/вправо, Home/End, roving tabindex и связанные tabpanel.
- Переключатель устройства использует `aria-pressed`, изображения имеют предметные alt.
- Увеличение снимка открывается в native `dialog`: клавиатурный фокус, Escape и возврат на вызвавшую кнопку.
- FAQ использует native `details/summary`.
- Есть skip link, видимый keyboard focus, `prefers-reduced-motion` и responsive layout.
- Без JS все четыре категории остаются доступны; декоративные переключатели скрываются.

Живой браузерный осмотр размеров 320/390/800/1440 выполняет основной агент задачи отдельно. Механические проверки этого пакета описаны в `validation.json`. Повторный прогон: `python3 brain-evolution/_tools/validate.py` (Pillow). Синтаксис JavaScript проверен Node `--check`. Непервичные подписи на светлом фоне проверены по контрасту и затемнены для читаемости малого текста.
